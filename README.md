# Big Butt Association - Shopify Theme

A custom Shopify Liquid theme for [Big Butt Association](https://bigbuttassociation.com/), converted from Next.js to a fully integrated Shopify storefront.

## Overview

This project represents a complete conversion of a Next.js website into a custom Shopify Liquid theme. The theme features a vibrant neon aesthetic, custom product displays, member benefits system, and seamless integration with Shopify's e-commerce platform.

## Live Site

🌐 **Live Website:** [bigbuttassociation.com](https://bigbuttassociation.com/)

## Tech Stack

- **Shopify Liquid** - Theme templating
- **Custom CSS** - Neon effects, animations, responsive design
- **JavaScript** - Interactive features, cart functionality, carousels
- **Shopify API** - Customer accounts, cart management, product integration

## Key Features

- Custom neon-themed design system
- Responsive mobile-first layout
- Product carousel with auto-play and manual controls
- Member benefits and BekkyBucks loyalty system
- AJAX cart functionality
- Custom customer account pages
- Newsletter integration
- Instagram social links

## Project Status

✅ **Live and Production-Ready**

The theme has been successfully deployed and is currently serving as the brand's primary website. The conversion from Next.js to Shopify Liquid presented a learning curve, but resulted in a fully functional, integrated e-commerce experience.
