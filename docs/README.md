# Documentation Index

This folder contains all project documentation organized by category.

## 📁 Folder Structure

### `/setup`
Setup and configuration guides for various features:
- **CUSTOMER_ACCOUNTS_SETUP.md** - Guide for setting up customer accounts (Classic vs Customer Account API)
- **CUSTOMER_ACCOUNT_API_CUSTOMIZATION.md** - How to customize Customer Account API pages
- **GOOGLE_SSO_SETUP.md** - Google SSO/OAuth configuration
- **PAGE_SETUP_GUIDE.md** - How to create and configure pages in Shopify Admin
- **SHOP_PAGE_SETUP.md** - Shop page ("Da Goods") setup instructions

### `/deployment`
Deployment, pushing changes, and troubleshooting deployment issues:
- **SHOPIFY_PUSH_STEPS.md** - Step-by-step guide for pushing theme changes
- **DEPLOYMENT_CLARIFICATION.md** - Explanation of deployment process
- **PUSH_CHANGES_NOW.md** - Quick reference for pushing changes
- **WHY_CHANGES_NOT_LIVE.md** - Troubleshooting why changes aren't visible
- **TROUBLESHOOT_CACHE.md** - Cache troubleshooting guide

### `/conversion`
Documentation from the Next.js to Shopify Liquid conversion:
- **CONVERSION_COMPLETE.md** - Summary of completed conversion
- **CONVERSION_CHECKLIST.md** - Checklist of conversion tasks
- **SHOPIFY_INTEGRATION.md** - Integration details and architecture

### `/fixes`
Bug fixes, patches, and troubleshooting guides:
- **FIXES_APPLIED.md** - Record of applied fixes
- **FIX_TEMPLATES.md** - Template fixes
- **QUICK_FIX_TEMPLATES.md** - Quick template fixes reference
- **ROUTING_FIXES.md** - Routing and navigation fixes
- **GALLERY_PAGE_FIX.md** - Gallery page specific fixes

### `/documentation`
General documentation and explanations:
- **CUSTOMER_PAGES_EXPLANATION.md** - Explanation of customer page structure
- **SEO_GUIDE.md** - SEO best practices and implementation
- **README.md** - Main project README (moved from root)

## 🔍 Quick Reference

- **Setting up a new feature?** → Check `/setup`
- **Deploying changes?** → Check `/deployment`
- **Understanding the codebase?** → Check `/conversion` and `/documentation`
- **Something broken?** → Check `/fixes`
